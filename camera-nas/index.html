Local NAS Backups & Camera Installation

Practical storage and hardware work for a five-person welding business.

← Back to Projects

Local file backups

I set up a NAS that two office computers access over Ethernet with password-protected access. The NAS is not connected directly to the router. Staff copy files to it as needed, and I also perform backups periodically.

The normal workflow is primarily manual. I used AI assistance to create a Python backup utility intended to simplify copying files, but it has not replaced the shop's usual manual process.

Recovery testing

I have not performed a snapshot restore test. My next step is to review the backup configuration and document a recovery test using noncritical files. This distinguishes having backup copies from demonstrating that a recovery process works.

Separate camera system

I installed four cameras connected to a DVR with its own storage. Video recording is separate from the NAS file-backup storage.

What I learned

The project gave me experience connecting hardware, setting up access and supporting a workflow used by other people. It also highlighted the importance of making backups easy to perform and checking that files can actually be restored.
