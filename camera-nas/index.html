Case study

NAS Backups & Camera Installation

Backup storage and a camera system for a small welding shop.

Role
IT Administrator, Ehlert Welding Co., Inc.
Tools
NAS, Ethernet, DVR camera system

File backups

I set up a NAS that two office computers reach over Ethernet, with password-protected access. Staff copy files to it when they need to, and I run backups on a regular basis too.

Restore testing

I've tested restoring files from the NAS to make sure the backups actually work when we need them.

Cameras

I installed four cameras connected to a DVR with its own storage, kept separate from the NAS.

What I learned

Backups only help if people actually make them and the files come back when you need them. Keeping the process simple for the office and testing restores myself covers both.
